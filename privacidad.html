Política de privacidad

Aplicación: Finanzas personales. Vigente desde el 17 de noviembre de 2026.

Finanzas personales es una herramienta de uso personal, de un solo usuario, que corre en la computadora de quien la usa. Esta política explica qué datos de Google lee, para qué, dónde quedan y cómo revocar el acceso.

Qué datos se leen

La aplicación lee únicamente los avisos de consumo de la tarjeta que llegan al correo de Gmail del usuario. Para eso usa el permiso de solo lectura de Gmail (gmail.readonly): puede leer correos, pero no puede modificar, enviar ni borrar nada.

Para qué se usan

La información de esos avisos se usa con un único fin: armar un tablero de gastos personal del propio usuario. No se le da ningún otro uso.

Dónde quedan los datos

  • Los datos quedan solo en la computadora del usuario.
  • No hay servidores: la aplicación no sube la información a ningún lado.

Qué no se hace con los datos

  • No se comparten con terceros.
  • No se venden.
  • No se usan para publicidad.
  • No se usan para entrenar modelos de inteligencia artificial.

Cómo revocar el acceso

El usuario puede quitarle el acceso a la aplicación en cualquier momento desde la configuración de su cuenta de Google: https://myaccount.google.com/permissions.

El uso y la transferencia de la información recibida de las API de Google cumplen con la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

Contacto

Por cualquier consulta sobre esta política, el contacto es el perfil de GitHub: github.com/sanhuezatupac-boop.
